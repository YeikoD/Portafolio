LogSys — Gestión de Inventario y Personal

Sistema empresarial ligero para la gestión de inventario y personal, diseñado para funcionar eficientemente en equipos con recursos limitados.

ASP.NET Core React Tauri 2 SQLite
  • Control de stock con trazabilidad de movimientos
  • Gestión de personal por cargos y departamentos
  • Autenticación JWT con roles y permisos
  • Instalador Windows autocontenido (sin .NET ni Node)
  • Reportes y exportación a Excel y PDF
  • Dashboard con gráficos de evolución y stock
